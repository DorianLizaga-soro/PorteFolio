# Portfolio — Dorian Lizaga-soro

Page unique en HTML / CSS / JavaScript, sans framework.

## Lancer
Double-clique sur `index.html` (ou utilise l'extension « Live Server » de VS Code).

## À remplacer par tes éléments
| Quoi | Où |
|---|---|
| Photo | `assets/images/profil.jpg` |
| Captures des projets | `assets/images/projets/selkabooth.jpg`, `flappy-die.jpg`, `gestion-salle.jpg` |
| CV | `assets/cv/CV-Dorian-Lizaga-soro.pdf` |
| Liens GitHub / LinkedIn | dans `index.html`, cherche `href="#"` (accueil et contact) |
| Liens FlappyDie / GestionSalle | dans `index.html`, section projets |
| Texte « À propos », frise | `index.html`, section `#about` |

## Organisation
- `css/base.css` : couleurs, police, reset
- `css/intro.css` : animation d'intro du Z
- `css/sections.css` : nav, fond, accueil, projets, à propos, contact
- `js/intro.js` : intro (traits, éclat, texte)
- `js/main.js` : texte qui s'écrit, nav, apparitions, fond animé
- `assets/logo/` : Z en SVG (3 traits, complet, blanc, favicon)

Le logo de la nav, l'intro et les filigranes sont déjà dans `index.html` (en SVG intégré).

## Mettre en ligne
GitHub Pages ou Netlify : envoie tout le dossier tel quel.
